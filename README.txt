M3U Tracker v3.0.0

INSTALL
1. Purono "M3U Tracker" plugin Deactivate korun (Delete korle-o data thakbe, table drop hoy na).
2. Plugins > Add New > Upload ei zip > Activate.
3. tv.php replace korun (public_html/tv.php).
4. .htaccess-e htaccess-snippet.txt-er code boshan.
5. WP Admin > M3U Analytics > Settings & Alerts e giye settings dekhe Save korun.

Purono wp_m3u_logs table-er data ager moto thakbe. Notun column (key_code, status) auto jog hoy.
